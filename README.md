# EnvironmentalEconomicsTrack2

Track 2 — Extreme events: a shift or a change in shape? Group project, BSc AIDAMS
Environmental Economics (ESSEC, 2026–2027).

Data: Copernicus Interactive Climate Atlas v2.5, ERA5-Land. TXx (June–August) and SPEI-6
(September) for Spain, France, Germany and Sweden, 1950–2025. Sources, definitions and
limitations are in `data/README.md`.

## Reproduce every result

Tested with Python 3.13.9. Run from the repository root:

```bash
pip install -r requirements.txt
python scripts/check_raw.py   # validates data/raw/, writes data/raw_check.csv
python scripts/analysis.py    # every result -> outputs/ (1.5 to 4 minutes, depending on the machine)
python -m pytest              # tests
```

Everything starts from the files in `data/raw/` exactly as downloaded; there is no manual
step. The periods, thresholds and bootstrap settings live only in `scripts/config.py`:
change them there and re-run `analysis.py`.

Bootstraps use a fixed seed, so a re-run on the same machine gives identical files. Results
should also match across machines at the precision written (4 decimals for derived tables):
this was tested by adding float noise of 1e-14 to the data, not on every platform, so treat a
difference in the last decimal on another machine as noise, not as a different result.

## Code

| File | Role |
|---|---|
| `scripts/config.py` | periods, thresholds, quantiles, bootstrap settings, paths |
| `scripts/load_data.py` | raw CSVs → one tidy table; TXx anomalies |
| `scripts/describe.py` | section 3 summary statistics |
| `scripts/tails.py` | shift vs shape (tail percentiles vs mean), threshold exceedances |
| `scripts/trends.py` | OLS trends with HAC errors, quantile regression |
| `scripts/bootstrap.py` | year-block bootstrap used for every confidence interval |
| `scripts/analysis.py` | entry point: writes everything in `outputs/` |

Other scripts (e.g. figures) should reuse the same data and settings:

```python
from config import EARLY, RECENT
from load_data import load_analysis_data

data = load_analysis_data()   # same table as outputs/analysis_data.csv
```

## Method choices (all set in `scripts/config.py`)

- **Periods**: early 1961–1990, recent 1996–2025 (30 years each).
- **Analysed variable**: TXx is expressed as an anomaly, in °C, from the early-period mean of
  the same country and month, then June, July and August are pooled (90 observations per
  country and period). SPEI-6 is used as published (30 per country and period).
- **Extremes**: upper tail of TXx (P75, P90, P95, P99), lower tail of SPEI-6 (P25, P10, P5, P1).
  Thresholds are computed on the early period and applied to both. Headline: P95 for TXx,
  P5 for SPEI-6. Percentiles use linear interpolation (numpy default).
- **Uncertainty**: bootstrap that resamples whole years (the three months of a summer stay
  together), 95% percentile intervals.
- **Trends**: per decade. OLS on one value per year with Newey-West HAC errors
  (lags = floor(4(T/100)^(2/9)) = 3), also re-estimated on 1978–2025 because ERA5-Land may be
  inconsistent before 1978. Quantile regression for τ = 0.05 … 0.95 with bootstrap errors,
  solved with statsmodels at `p_tol = 1e-8` (at the default 1e-6, float noise can move a slope
  by 0.002).

## Outputs (generated by `analysis.py` — never edit by hand)

Derived tables are written at 4 decimals, `analysis_data.csv` at 10 (raw values stay exact).

| File | Content |
|---|---|
| `analysis_data.csv` | tidy data behind every result: one row per series and year |
| `summary_stats.csv` | N, mean, SD, min, P1–P99, max by index, country and period (early, recent, full) |
| `table_summary.md` | Table 1 of section 3 (early vs recent) |
| `txx_baseline.csv` / `.md` | early-period mean TXx (°C) per country and month: the zero of the anomalies |
| `shift_shape.csv` | change in each tail percentile vs change in the mean, with bootstrap intervals |
| `exceedance.csv` | exceedances of early-period thresholds, observed and under a pure shift |
| `ols_trends.csv` | OLS trend per decade with HAC standard errors |
| `quantile_trends.csv` | quantile-regression trend per decade with bootstrap standard errors |

Columns that need a definition (`_lo` / `_hi` are the 95% interval bounds):

| Column | Meaning |
|---|---|
| `d_mean`, `d_sd`, `d_q` | recent minus early: mean, standard deviation, tail percentile |
| `shape` | `d_q - d_mean`: how far the tail percentile moved beyond the shift of the mean |
| `shape_extreme` | `shape` for TXx, `-shape` for SPEI-6: > 0 always means the tail moved further toward the extreme than the mean |
| `n_beyond_*`, `years_beyond_*` | observations beyond the period's own percentile, and the distinct years they come from |
| `threshold_value` | early-period percentile, applied to both periods |
| `k_*`, `rate_*`, `years_*` | number, share and distinct years of observations beyond the threshold |
| `k_shift_only`, `rate_shift_only` | the same for the early distribution shifted by `d_mean` (pure shift, no change in shape) |
| `excess_over_shift` | `rate_recent - rate_shift_only` |
| `n_beyond_line` | observations above (τ ≥ 0.5) or below (τ < 0.5) the fitted quantile line |
| `minus_median` | quantile slope minus median slope, interval from the same bootstrap draws |
| `series_nonconverged_fits` | fits of that series (point estimates and bootstrap draws, all τ) that hit the iteration limit |
